# YourHome Privacy Policy (Draft)

_Last updated: 2026-02-23 (Property Discovery draft update)_

## 1. What we collect
- Account identity data (name, email, auth provider id)
- Property/project data you submit
- App diagnostics and basic usage events

### Property Discovery (beta) data
If you opt in to Property Discovery, we may collect and process:
- Full legal name and known aliases you provide
- Current and prior addresses you provide
- Contact details used for matching (email/phone, if provided)
- Optional disambiguation data (for example month/year of birth)
- Public-record match candidates and metadata (county/source reference, parcel hints)
- Your verification decisions (claimed/rejected/unsure)
- Contact verification events (email and phone verification status/timestamps)
- Identity verification data for claim events (selfie + ID-check status and audit refs)

## 2. Why we collect it
- To provide the service and core features
- To improve reliability and security
- To support customer operations
- To help you identify likely property records when you explicitly opt in to Property Discovery

## 3. How data is used
- Service operation
- Security monitoring and abuse prevention
- Product quality improvements
- Candidate property matching and confidence scoring (Property Discovery beta)
- User-led verification before any property is linked to an account

## 4. Data sharing
- No sale of personal data
- Limited sharing with infrastructure/auth providers strictly required to operate the app
- For Property Discovery, limited sharing with record/data processors only as needed to retrieve and score match candidates

## 5. Retention
- Keep data as long as needed for service delivery, legal compliance, and security
- Support deletion/export requests where required
- Property Discovery candidate data is retained only as needed for matching, fraud prevention, and legal obligations; stale candidate sets should be pruned on a defined schedule

## 6. Security
- Industry-standard controls (access control, token hygiene, least privilege)
- Incident response process for critical events

## 7. Your rights
- Access, update, or request deletion (subject to legal limits)
- Opt out of Property Discovery at any time
- Request deletion of Property Discovery candidate data where legally permitted
- Contact support for data requests

## 8. Public-record sources and verification notice
- Property Discovery uses public-record sources and may include inaccuracies, stale records, or duplicate identities.
- Match results are candidates only until you verify them.
- YourHome should not auto-claim ownership without explicit user confirmation.

## 9. Changes to this policy
- We update this document when features/data practices change
- Material changes should be reflected before shipping user-facing features
